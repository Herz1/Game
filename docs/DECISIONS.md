# Production decisions — 灯潮：第八座灯塔 / Lantern Tides

Production date: 2026-09-24. All eleven root production documents have been read. They remain unchanged and retained as the brief; achieved scope and deviations will be recorded rather than silently redefining acceptance.

## Original identity
Eight travelers discover that the lighthouses which calm the sea consume people's memories of those they have lost. They must restore eight regional bells and confront the keeper who believes a painless, motionless world is salvation. The ending restores tides, uncertainty and freely chosen remembrance. All characters, maps, prose, formulas, art and score are original; no commercial game assets are imported.

## Executable architecture
The local execution container cannot resolve github.com and does not have Vite/Three.js installed. GitHub's connected API is available. Use strict TypeScript, a custom Canvas 2.5D diorama renderer, DOM/CSS game UI and WebAudio; compile with the installed TypeScript compiler and an offline single-file packer. No CDN, server, API key or external runtime dependency. This is a deliberate replacement of Three.js/Vite, not a claim of equivalent native 3D rendering. Keep compiled and source forms.

## Production priorities
Ship a real title-to-credits story with persistent post-ending exploration first. Expand to eight protagonists, eight settlements, eight routes, eight regional dungeons, a final region, equipment, jobs, side quests and optional bosses. Actual QA and content counts, not target counts, will determine the release report. No claim of AAA equivalence or perfection without evidence.

## Preservation
Never delete original brief files. Preserve code, source tables, generators, prompts, raw generated images, processed crops, original score notation, tests, screenshots and intermediate builds. The public repository must not host unlicensed third-party media. Original WebAudio music avoids third-party acquisition/redistribution problems. No MaouDamashii track will be imported unless its current license is actually checked.
